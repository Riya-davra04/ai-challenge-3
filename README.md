# Carbon Footprint Awareness Platform

## Overview
An AI-powered platform that helps users understand and reduce their carbon footprint through personalized recommendations.

## Features
- Carbon footprint awareness
- AI-generated suggestions
- User-friendly interaction

## Tech Stack
- Node.js
- Gemini API

## How to Run
1. Install dependencies
2. Add GEMINI_API_KEY in .env
3. Run the application

## Assumptions
- User provides accurate information
- Internet connection is available for AI responses
